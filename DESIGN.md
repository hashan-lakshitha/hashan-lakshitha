# Design System: Hashan Lakshitha GitHub Profile
**Project ID:** hashan-lakshitha-profile

## 1. Visual Theme & Atmosphere
A sleek, high-contrast "Cyber-Architect" dark aesthetic crafted for a senior national-level Software Engineer. Combines deep dark space canvas (#0D1117) with electric glowing cyan-blue gradients (#00F2FE to #4FACFE) and presidential gold highlights (#FFD700). The mood is authoritative, cutting-edge, fast, and secure—conveying enterprise engineering rigor alongside modern full-stack agility.

## 2. Color Palette & Roles
* **Midnight Canvas (`#0D1117`):** Primary background ensuring high-contrast readability for dark-mode interfaces.
* **Electric Cyan (`#00F2FE`):** Hero accent used for primary glowing banners, typing SVG titles, and highlight borders.
* **Deep Neon Azure (`#4FACFE`):** Secondary gradient transition color for fluid visual motion and badges.
* **Presidential Amber Gold (`#FFB703`):** High-priority accent designating national government project achievements.
* **Card Slate Surface (`#161B22`):** Elevated container background for project cards, tech stack grids, and metrics.
* **Muted Silver (`#8B949E`):** Secondary body text and structural dividers.

## 3. Typography Rules
* **Header Font:** Outfit / Fira Code (rendered in Typing SVG & Banner graphics) for futuristic readability.
* **Body Font:** System UI / -apple-system / Segoe UI for crisp cross-platform rendering in GitHub Markdown.
* **Weights:** Bold (700) for section titles and key metrics; Medium (500) for badge labels; Regular (400) for descriptive summaries.

## 4. Component Stylings
* **Animated Header Waving Banner:** Dynamically rendered Capsule Banner (`capsule-render`) featuring a soft organic wave shape with an electric gradient overlay.
* **Typing Animation Header:** Dynamic multi-line typing effect (`readme-typing-svg`) cycling through key engineering identities.
* **Tech Stack Badges:** Pill-shaped badges using `for-the-badge` style with custom hex background tones and official brand logos.
* **Project Cards & Grid:** Structured Markdown tables with custom emoji indicators, direct hyperlinked domain badges, and functional tags.
* **GitHub Analytics Dashboard:** Harmonized dark-themed statistical cards (`theme=tokyonight` / `theme=cyberpunk`) displaying repository activity, streak records, and language breakdowns.

## 5. Layout Principles
* **Centered Hero Anchor:** Eye-catching top banner and dynamic text typing component aligned to center stage.
* **Asymmetric Grid Organization:** Tech stack grouped cleanly by technical domain (Languages, Frontend, Backend, Cloud/DevOps).
* **Section Separation:** Sleek horizontal gradient rules (`<hr>` & SVG dividers) creating distinct visual focus zones.
* **Dynamic Motion:** Responsive SVGs that animate continuously without relying on external heavy video payloads.
